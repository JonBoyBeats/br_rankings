College projections as uploaded each week, kept to backtest the sources against results.

- `<season>_wNN_cff.csv`: the CFF export (PLAYER NAME, FPNTS).
- `<season>_wNN_fp.csv`: the Fantasy Points export (NAME, FPTS under a banner row).

NN is the CFBD week, the same numbering as `analysis/cfb.json` and the box scores in
`analysis/cfb/cache/<season>_wNN_v2.json`, whose `fp` is each player's actual half-PPR.
Save the last version uploaded before kickoff.
